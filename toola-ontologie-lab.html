Toola Ontologie Lab.

Veřejná vstupní stránka pro koncept Toola: optimalizace energetického řetězce, BESS a resilience planning, provenance dat, ontologická struktura a odkaz na živou vývojářskou aplikaci.

Co tato stránka vysvětluje

Toola není prezentována jako obecný web builder ani jako statický obrázek. Jde o rozhodovací prostředí pro komplexní energetické systémy výzkumných infrastruktur. Veřejný web má vysvětlit metodu, datové toky, ontologii a exploitation pathway; živá aplikace zůstává hostovaná samostatně.

Samostatný hosting aplikace

Aplikace Toola zůstává hostovaná samostatně a z webu je pouze odkazovaná. Osobní web nemusí hostovat výpočetní jádro.

Použitelnost mimo GitHub

GitHub je vhodný pro kód a archivaci, ale není dostatečně přívětivý jako hlavní prostředí pro obecnou vědeckou veřejnost. Web má vytvořit vysvětlující vrstvu.

Traceability a exploatace

Stránka zdůrazňuje provenance dat, metodiku, příkladové výstupy, dokumentaci a roli GitHub/Zenodo archivace po skončení projektu.

Přidaná analytika webu

Do celého webu je vložena privacy-friendly Plausible-ready analytika. Po založení domény v Plausible bude měřit návštěvy a navíc zachytí kliky na e-mail, telefon, LinkedIn, PDF soubory, detaily služeb a živý odkaz na aplikaci Toola.
